---
description: Commit, push, and open a PR
---

以下の手順でコミット、プッシュ、PRの作成を行ってください：

## 1. 変更の確認
- `git status` で変更されたファイルを確認する
- `git diff` で変更内容を確認する

## 2. コミット
- 変更内容を分析し、Conventional Commits形式で適切なコミットメッセージを生成する
  - 例: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:` など
- すべての変更をステージングしてコミットする

## 3. プッシュ
- 現在のブランチをリモートにプッシュする
- 必要に応じて upstream を設定する

## 4. PR作成
- GitHub CLI (`gh`) を使用してPRを作成する
- PRのタイトルはコミットメッセージに基づいて設定する
- PRの説明には変更内容のサマリーを含める

## 注意事項
- 各ステップの実行前に確認を求めること
- エラーが発生した場合は適切に対処すること
